# 🎓 Student Grade Calculator

A simple and beginner-friendly web application that calculates a student's total marks, percentage, and grade based on marks entered in five subjects.

## ✨ Features

- Enter student name
- Input marks for five subjects
- Calculate total marks out of 500
- Automatically calculate percentage
- Assign grades based on percentage
- Validate marks between 0 and 100
- Clean and responsive user interface

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling and layout
- **JavaScript** — Calculations, validation, and grade logic

## 📚 Subjects

- English
- Physics
- Mathematics
- Chemistry
- Computer Science

## 📊 Grading System

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89% | A |
| 70–79% | B |
| 60–69% | C |
| 40–59% | D |
| Below 40% | F |

*Note: This is a sample grading system used for this project.*

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter the student's name and marks.
5. Click **Calculate Grade** to view the result.
